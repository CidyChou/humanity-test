# HUMAN / 01 — 人类退化测试 V3.0

## 启动
直接用现代浏览器打开 `index.html`，或在 macOS / Linux 终端执行：

```sh
chmod +x start.sh
./start.sh
```
默认端口 8765（可传入自定义端口）。脚本打印本地和局域网地址。无外部资源、无 API Key、无需安装依赖。手机需与电脑在同一局域网。

## 评分协议 H01-P02
8 项固定任务，逐级增加复杂度。每项满分 100，原始分与独立评估分分别记录；每关一次正式结算，无准备页、无中途成绩页；完成、超时或抵达导航终点自动进入下一关，最终报告统一展示成绩和复盘。各项权重分别为 8%、10%、12%、12%、13%、13%、12%、20%。综合分为独立评估分的加权总和，保留一位小数。AI 提示后计原始分的 70%，AI 代做计 0。AI 依赖记录：提示 8、代做 20，每项只计一种，最大 100。

| 项目 | 规则 |
|---|---|
| 心算 | 每题等权，未答或错答计零 |
| 记忆 | 按输入位置逐位比较，允许部分分，不即时提示正误 |
| 导航 | 70 × max(0, 1 − 路线编辑距离/标准路线步数) + 30 × 是否到达 − 5 × 碰撞次数，限制在 0–100 |
| 编程 | 取电池35分、到达35分；成功且无碰撞时效率分为30 × 最优指令数/实际指令数，碰撞扣10 |
| 筛选 | 100 × max(0, 命中数 − 误选数)/目标数 |
| 终极关 | 20步路线、5秒观察、50秒作答；必须完全匹配且零碰撞、按时抵达才算极限挑战通过 |

S：综合 ≥90、全部独立且极限通过；否则 A ≥80、B ≥65、C ≥45、D <45。等级为游戏设计阈值，不是人口常模。5% 为目标首试通过率，尚未通过真实样本验证。

本地记录存于 localStorage，V3.0 沿用 V2 存档及 H01-P02 评分协议，不覆盖 V1。测试开始后退出或刷新，本项视为中断记0（浏览器允许 localStorage 的情况下）；已完成成绩保留。重复挑战允许提高成绩。离线版本不具备服务器签名、跨设备防作弊或真实人群排名。成绩卡可保存 PNG，报告可分享或复制。

## V3.0 验证
Chromium 390×844 模拟移动视口：8 项自动开始、完成自动进入下一项，无中途评分页；八项正确作答 100/S；最终报告保留 6 项逐题复盘；两道导航关抵达指定终点自动结算；记忆部分分（3/6 = 50）；导航抵达但多走两步（87）；AI 提示（100→70）；AI 代做（100→0）；超时和主动中断；PNG 导出。自动化测试的观察时长可缩短以加快验证，发行版本使用原定时长。未进行真实手机设备、人群难度校准或临床验证。
